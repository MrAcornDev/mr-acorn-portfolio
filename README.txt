# Mr Acorn — Roblox Portfolio

## Quick start
1. Open `index.html` in your browser.
2. Edit the text in `index.html` to add your real bio, skills, project names, Roblox link, and Discord.
3. Put your screenshots in `assets/images/`.
4. Put your videos in `assets/videos/`.
5. Replace the placeholder blocks in `index.html` with `<img>` or `<video>` elements as shown below.

### Image example
```html
<img src="assets/images/project-1.jpg" alt="My Roblox build">
```

### Video example
```html
<video controls poster="assets/images/video-cover.jpg">
  <source src="assets/videos/showcase-1.mp4" type="video/mp4">
</video>
```

The design is responsive and works on desktop and mobile.
